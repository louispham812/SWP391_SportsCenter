Concurrency Control & Double-Booking Protection

Zero Collision Guarantee
1
Slot Selection
User picks court date and start/end time.
→
2
Conflict & Lock Check
DB checks existing bookings & maintenance.
→
3
10-Min Reservation Hold
Slot locked in PENDING status.
→
4
Payment or Timeout
PAID confirms; timeout releases slot.
🔒
HTTP 409 Conflict Rejection
Real-Time Collision Guard
If two users click checkout simultaneously for the same court and timeframe, the backend transaction isolation immediately aborts the second attempt with HTTP 409 Conflict: "Court slot is currently reserved or under maintenance."
🛡️
Maintenance Interval Interception
Instant Facility Lockdown
When an Admin schedules maintenance or locks a court, any active slot in that timeframe is instantly disabled across both public catalog and member booking views. Existing bookings trigger automated warning logs.
02 • System Design

Smart Quota Precedence & VIP Discount Engine

Automated Billing Logic
⚡
Quota-First Deduction Rule
Optimized Checkout Flow
When a member books a court or registers for a class/PT session:
  • Step 1 (Check Active Package): Query user_memberships for valid VIP/PT/CLASS packages with remaining quota.
  • Step 2 (Quota Deduct): If quota > 0, system decrements 1 session quota and confirms booking with zero payment required ($0).
  • Step 3 (Gateway Fallback): If quota is exhausted (0), seamlessly route to VNPay / Sandbox payment checkout.
👑
Tiered VIP Pricing & Stackable Vouchers
Dynamic Discount Evaluation
If paying via online payment, the pricing engine applies stacked discounts:
  • Silver Member: 15% automatic discount on all court bookings.
  • Gold Member: 30% automatic discount on courts & classes.
  • Diamond Member: 50% discount on entire service catalog.
  • Voucher Code: Input promotional vouchers (e.g. FINAL50K) applied after tier discount.
02 • System Design

Automated 100% Refund & Financial Integrity

Zero Balance Discrepancy
⏱️
> 2h Auto Refund
Strict Business Rule
Members canceling a court booking more than 2 hours before the scheduled start time receive an instantaneous 100% automated refund, immediately releasing the slot to other users.
🚫
< 2h Non-Refundable
Late Cancellation Lock
Within 2 hours of game time, cancellations are non-refundable to protect center operations and prevent last-minute abandoned reservations. The cancel button is disabled in UI and rejected by API.
🔐
Idempotent Webhooks
HMAC SHA-512 Security
Payment callback handlers verify cryptographic signatures and enforce idempotency keys, guaranteeing that network retries or duplicate webhook signals never generate duplicate ledger entries.
📝
Online Refund Request Workflow (Anti-Spam Protocol)
Single-Entry Accounting Verification
For complex transactions, members submit bank account details via /member/transactions. The system prevents duplicate PENDING submissions. Upon Admin approval, the original transaction updates directly to REFUNDED, preserving a pristine audit trail.

06 • Conclusion & Q&A

Anticipated Committee Defense Questions & Answers

Architectural Defense
Q1
How does the system handle booking race conditions?
Concurrency & Peak Load Defense
Answer: We enforce an immediate 10-minute slot reservation hold inside a serializable database transaction. A secondary collision attempt immediately fails validation and returns HTTP 409 Conflict.
Q2
How do you ensure zero financial discrepancies at POS?
Reconciliation Integrity Defense
Answer: Every cash, card, and quota transaction creates an immutable payment record tied to staff ID (approvedBy). Shift handover aggregates sum real-time payments, aligning with the admin ledger with zero delta.
Q3
Why choose Quota Precedence over flat discounts?
Business Model Rationale
Answer: Multi-sport members purchase bundled credits in advance. Quota deduction reduces checkout friction to zero clicks ($0 gateway charge), significantly increasing member booking velocity.
Q4
How do you prevent AI Coach hallucinations?
AI Safety & Guardrails
Answer: The Gemini prompt is bounded by structured system instructions injecting validated member physiological data (BMI, SMM, 1RM) and includes medical disclaimers prohibiting clinical diagnosis.
